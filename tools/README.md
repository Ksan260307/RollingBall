# 開発用ツール

このフォルダの中身は**開発中だけ**使うもので、配信物には含まれません。
`npm run build` の入口は `index.html`（ゲーム本体）だけに固定してあるため、
ここのファイルが `dist/` に入ることはありません。

## コースエディタ

```bash
npm run dev
```

ブラウザで **http://localhost:5173/tools/course-editor/** を開きます。

### できること

| 場所 | 内容 |
| --- | --- |
| 上のタブ | コースの切りかえ。追加・削除もここ |
| 左のパネル | コース名・むずかしさ・めやすタイム・横風・色、そして「つなぎ」の一覧 |
| つなぎ 1 行 | 長さ・曲がり・下り・幅・傾き・床の種類・壁・とぎれ |
| 右の 3D | ドラッグでまわす、ホイールで寄る・引く。黄色い玉がスタート地点 |
| 右上の数字 | 全長・高低差・平均勾配・つなぎ数 |

### ボタン

- **ためし走行** — ゲーム本体と同じ自動運転でコースを走らせ、完走できるか・何秒かかるかを出します。
  完走できないコースはその場でわかります
- **本編に反映** — `src/game/courses.json` に直接書きこみます。ゲームの画面を読みこみ直せばすぐ遊べます
- **読みなおす** — ファイルの内容に戻します（編集の破棄）
- **JSONをコピー** — クリップボードに JSON を出します

### しくみ

コースの定義は `src/game/courses.json` に置いてあり、**ゲームもエディタも同じファイルを読みます**。
そのため「エディタで作ったものを本編に持っていく」作業はありません。保存＝反映です。

書きこみは開発サーバーのミドルウェア（`vite.config.ts` の `courseSaving`）が受けもちます。
`apply: 'serve'` を指定してあるので、ビルド結果にはこの口自体が存在しません。

`courses.json` は手で編集してもかまいません。読みこみ側（`src/game/stages.ts`）は
項目が欠けていても極端な値でも既定値で補うので、壊れて起動しなくなることはありません。
