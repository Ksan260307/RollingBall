# 開発用ツール

このフォルダの中身は**開発中だけ**使うもので、配信物には含まれません。
`npm run build` の入口は `index.html`（ゲーム本体）だけに固定してあるため、
ここのファイルが `dist/` に入ることはありません。

## コースエディタ

```bash
npm run dev
```

ブラウザで **http://localhost:5173/tools/course-editor/** を開きます。

### できること

| 場所 | 内容 |
| --- | --- |
| 上のタブ | コースの切りかえ。追加・削除もここ |
| 左のパネル | コース名・むずかしさ・めやすタイム・横風・色、そして「つなぎ」の一覧 |
| つなぎ 1 行 | 長さ・曲がり・下り・幅・傾き・床の種類・壁・とぎれ |
| 右の 3D | ドラッグでまわす、ホイールで寄る・引く。黄色い玉がスタート地点 |
| 右上の数字 | 全長・高低差・平均勾配・つなぎ数 |

### ボタン

- **ためし走行** — ゲーム本体と同じ自動運転でコースを走らせ、完走できるか・何秒かかるかを出します。
  完走できないコースはその場でわかります
- **本編に反映** — `src/game/courses.json` に直接書きこみます。ゲームの画面を読みこみ直せばすぐ遊べます
- **読みなおす** — ファイルの内容に戻します（編集の破棄）
- **JSONをコピー** — クリップボードに JSON を出します

### しくみ

コースの定義は `src/game/courses.json` に置いてあり、**ゲームもエディタも同じファイルを読みます**。
そのため「エディタで作ったものを本編に持っていく」作業はありません。保存＝反映です。

書きこみは開発サーバーのミドルウェア（`vite.config.ts` の `courseSaving`）が受けもちます。
`apply: 'serve'` を指定してあるので、ビルド結果にはこの口自体が存在しません。

`courses.json` は手で編集してもかまいません。読みこみ側（`src/game/stages.ts`）は
項目が欠けていても極端な値でも既定値で補うので、壊れて起動しなくなることはありません。

### 床の種類

| 表示 | 内容 |
| --- | --- |
| ふつう | よく食いつく標準の床 |
| すべる | 摩擦が小さい。急な坂では直進していても滑る |
| あらい | よく食いつくが、転がり抵抗が大きい |
| 加速 | 進行方向へ押し出す |

## 宣伝動画をつくる

```bash
npm run dev
```

ブラウザで **http://localhost:5173/tools/promo/** を開き、「録画する」を押します。
15 秒ほど待つと `promo/promo.webm`（1280×720）が書き出されます。

### しくみ

ゲームを**実際に動かして**録っています。作りものの映像ではありません。
自動運転（タイトル画面と同じもの）でコースを走らせ、カットごとに
コース・ボール・カメラ位置を切りかえ、その絵を 2 枚目のキャンバスに写して
文字を乗せ、そちらを録画します。

録画中はタブを前面のままにしてください。裏に回すとブラウザが描画を止めるため、
そのぶん映像が飛びます。

### カット割り

| 時間 | 内容 |
| --- | --- |
| 0.0–2.9 | はじまりの丘を真横から・タイトル |
| 2.9–5.4 | 後方から、走行 |
| 5.4–7.7 | 星ふる回廊。細い足場 |
| 7.7–10.1 | ランダム形状のボールに寄る |
| 10.1–13.5 | ゴール。突き抜けて飛んでいく |
| 13.5–15.0 | 終わりの画面 |

カット割り・文字・長さは `tools/promo/main.ts` の `SHOTS` を書きかえれば変わります。

### 書き出しについて

保存先は開発サーバーのミドルウェア（`vite.config.ts` の `filmSaving`）が受けもちます。
`apply: 'serve'` なので、ビルド結果にこの口は存在しません。
`promo/` は `.gitignore` に入れてあります（必要なときに録りなおすもので、履歴に残すものではありません）。

形式は webm（VP9）です。mp4 が必要なら ffmpeg で変換してください。

```bash
ffmpeg -i promo/promo.webm -c:v libx264 -pix_fmt yuv420p promo/promo.mp4
```
